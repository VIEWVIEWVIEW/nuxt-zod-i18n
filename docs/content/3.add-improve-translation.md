You can help to translate this module. 

Zod now maintains the built-in error messages. If you spot an issue or a missing locale, consider opening a pull request on the [official Zod locale directory](https://github.com/colinhacks/zod/tree/master/src/v4/locales).

You can still fine-tune the copy in your project by overriding the `zodI18n` namespace inside your own Nuxt I18n locale files.
